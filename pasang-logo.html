Pasang logo SMAN 2 ke MathSpace

Logo sudah tertanam di file pemasang ini. Tidak perlu mengunggah foto lagi atau menulis kode.

  1. Pilih style.css versi terakhir yang ada di folder website.
  2. Tekan Unduh style.css dengan logo.
  3. Simpan hasil unduhan menggantikan style.css lama di folder website, lalu muat ulang halaman.

Pemasang mempertahankan isi CSS lama, termasuk foto developer dan pemuatan foto kelompok. Hanya menambahkan aturan logo di bagian sekolah. Jika foto kelompok belum tampil sebelumnya, pemasangan logo ini tidak otomatis memperbaiki masalah foto kelompok.
