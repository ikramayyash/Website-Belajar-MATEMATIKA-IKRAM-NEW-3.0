Paket lengkap MathSpace, tanpa mengedit kode

Alat ini menggunakan file website terbaru dari perangkatmu, memasukkan revisi header ke kedua halaman, lalu mengemas semuanya menjadi satu ZIP. Foto tertanam dan file pendukung yang tersedia tetap dipertahankan.

  1. Pilih folder website yang langsung berisi index.html, geometri.html, style.css, dan script.js.
  2. Jika browser meminta konfirmasi, izinkan pembacaan file folder tersebut.
  3. Klik Buat dan unduh paket lengkap.
  4. Ekstrak ZIP ke folder baru, lalu buka index.html di dalamnya.

    Belum ada folder dipilih.

    Unduh ulang ZIP

    File hanya dibaca dan diproses dalam browser; tidak dikirim ke server. Folder asli tidak ditimpa. .git, node_modules, konfigurasi editor, dan arsip ZIP tidak disertakan. Alat ini memperbaiki posisi ikon menu/tema dan gradasi MathSpace, bukan menyediakan gambar yang tidak ada dalam folder sumber.

    Halaman ini adalah pengemas lokal, bukan halaman website final. ZIP final baru tersedia setelah folder dipilih dan proses selesai.
